### What I'm working on

- At **CNRS CerCo**, under Rufin VanRullen, I'm building a Global Workspace over vision, touch and proprioception on HumanoidBench, a simulated humanoid benchmark, with the goal of training a DreamerV3 agent to act from it. Before that I trained GRU-based Global Workspace models on Atari Pong.
- With the **inzva AI Projects** team I'm building a Turkish medical LLM from agentic RAG and supervised fine-tuning. It is meant to run on a hospital's own server.
- On **TechTipsWiki**, a platform of alternatives to mainstream tech products, I write the backend in FastAPI and PostgreSQL. The frontend is React, served with Nginx in Docker.
